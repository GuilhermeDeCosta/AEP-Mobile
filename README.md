# Passo a passo para iniciar o mobile de forma prática  
  
1°Passo deve ser iniciar a API em https://github.com/GuilhermeDeCosta/AEP-Back  
  
2° Passo é cadastrar alguma peça na aplicação Web: https://github.com/GuilhermeDeCosta/AEP-Front
  
3° Passo acesse o site https://snack.expo.dev/ e cole o código na pasta expo snack deste mesmo repositório
  
4° Passo é adicionar as dependencias do Axios, só apertar em "Add Dependency" que está no erro em vermelho  
  
5° Passo  é apertar para expandir em uma nova tela do lado da versão "Web"
